## Worktree Safety

The updated run sheet contains no recursive filesystem deletion, `git clean`, `git checkout .`, forced worktree removal, or forced branch deletion. Setup refuses path reuse. Cleanup refuses an unregistered or dirty worktree, asks for the exact `REMOVE` confirmation, then uses `git worktree remove` and `git branch -d` without force.
